
# Purr & Pour Cafe

CCT360 Lab 6 – Bootstrap 6 Two-Page Website

## About the Project

Purr & Pour Cafe is a fictional cat cafe website created for CCT360 at the University of Toronto Mississauga.

The website uses a soft pastel theme and introduces six adorable cats.

## Features

- Responsive navigation bar and mobile drawer menu
- Three-slide image carousel
- Six cat cards with expandable details
- Interactive dialogs for each cat
- Contact page with a six-field form
- Custom pastel CSS theme

## Technologies

- HTML5
- CSS3
- Bootstrap 6
- JavaScript provided by Bootstrap

## Pages

- index.html – Home page
- Contact.html – Contact form
